## 这是什么

一份**实测出来的**浏览器自动化反检测手册。

不是抄 MDN 的补丁清单，是「这套补丁在哪个平台没用、为什么没用、那该怎么办」。

## 核心结论（先看这条）

**反检测能提高通过率，不能保证通过。**

最反直觉的一条实测：视频号下载场景，上了全套补丁仍然被拦——因为它是 **IP + 自动化特征**双重判定，补丁只解决特征这一半。

所以第一步不是加补丁，是**先判断你面对哪种拦截**：

| 判定维度 | 补丁有用吗 | 该怎么办 |
|---|---|---|
| 前端特征（webdriver、指纹） | 有用 | 上补丁 |
| IP 级风控（冷却、限频） | 没用 | 降频、换时段、人工介入 |
| 账号画像 | 没用 | 养号、稳定环境 |
| 行为节奏 | 部分有用 | 随机延迟、走真实点击链路 |
| 端口探测 | 补丁没用 | 别挂 CDP，改扩展自检 |

## 内容

- 基础补丁（webdriver / plugins / languages / permissions）
- 行为层（逐字符输入、随机延迟、真实点击链路）
- 端口探测型反爬的识别与处置（BOSS 直聘实测）
- IP 级冷却的判断（视频号实测）
- 无头 vs 有头 的选择表
- 一条底线：反检测不是用来绕过平台安全措施的

## 适用场景

- 自建 Playwright / Puppeteer 采集器时反复被识别
- 页面莫名其妙变白、被踢出登录
- 控制台出现对本机端口的探测请求
- 想判断「到底是我的脚本不行，还是 IP 被限了」

## 不适用

- 平台有官方 API 的情况 —— 走官方
- 需要绕过登录墙或付费墙 —— 不做
